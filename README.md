# Finance Tracker

Финансовый трекер — PWA-приложение для учёта личных расходов. Позволяет удобно фиксировать траты, смотреть базовую аналитику прямо в приложении (куда уходят деньги и сколько тратится на то или иное), а для глубокого анализа — экспортировать данные в JSON и отдать их, например, GPT.

**Приложение:** https://kirillmukh.github.io/finance-tracker/

**Лендинг с инструкцией по установке:** https://kirillmukh.github.io/finance-tracker/landing.html

**Демо-режим (тестовые данные):** https://kirillmukh.github.io/finance-tracker/?demo=1

## Возможности

- Учёт транзакций: описание, сумма, категория, теги, дата и время
- Оценка каждой траты: «плохая» / «ок» / «осознанная»
- Диаграммы по категориям, оценкам и тегам с интерактивной легендой
- Фильтр по периоду (день / неделя / месяц / год / свой диапазон) и по категории — кликом по сектору диаграммы
- Тёмная тема (системная / светлая / тёмная)
- Импорт и экспорт всех данных в JSON — единственный способ синхронизации между устройствами
- Демо-режим с тестовыми данными, чтобы посмотреть приложение до ввода своих трат
- Работает офлайн: приложение — PWA с сервис-воркером, устанавливается на телефон и компьютер

## Приватность

1. Все данные хранятся локально на вашем устройстве (IndexedDB + localStorage)
2. Синхронизация между устройствами — только вручную, через импорт-экспорт
3. Никакие данные не собираются: нет ни одного сетевого запроса с вашими данными, нет аналитики и трекинга — всё прозрачно для пользователя

Главный минус: каждую транзакцию нужно вводить вручную, что требует дисциплины. Проект развивается.

## Использование

Первым делом установите приложение по инструкции в конце [лендинга](https://kirillmukh.github.io/finance-tracker/landing.html) или используйте как вкладку в браузере (главное — не очистите случайно данные сайта, они хранятся в браузере).

В приложении три раздела:

1. **Главная** — список всех транзакций, диаграммы и фильтры
2. **Настройки** — импорт и экспорт данных, тема, тег и оценка по умолчанию, переименование тегов
3. **Добавление** — форма для добавления транзакций

## Разработка

Без сборки и фреймворков — чистый JavaScript (ES-модули), Chart.js подключается с CDN. Для запуска достаточно раздать статику:

```sh
python -m http.server 8080
```

Тесты — Vitest + jsdom + fake-indexeddb:

```sh
npm install
npm test              # запустить все тесты
npm run test:watch    # режим наблюдения
npm run test:coverage # отчёт о покрытии
```

Деплой на GitHub Pages происходит автоматически при пуше в `master`.
